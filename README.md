# IndiaKart-E-Commerce-Analytics-project
End-to-end E-Commerce Analytics project using Excel, Power Pivot and Power BI. Includes data cleaning, business KPIs, interactive dashboards and management insights.
📌 Project Overview

IndiaKart E-Commerce Analytics is an end-to-end data analytics project focused on understanding business performance, customer behaviour, sales trends, payment performance, and inventory management.

The project uses Excel, Power Pivot, and Power BI to transform raw e-commerce data into meaningful business insights through KPI analysis and interactive dashboards.
